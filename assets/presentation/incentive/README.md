# Imágenes de la mejora por contratación anticipada

Estas cuatro imágenes se usan en la diapositiva fija de la mejora adicional disponible cuando el cliente confirma el proyecto dentro de los 15 días siguientes a la presentación.

- `roller_shutter.png`: motorización de persiana.
- `insect_screen.png`: mosquitera enrollable o plisada.
- `aluminium_sill.png`: forro de peana con chapa de aluminio.
- `other_improvements.png`: otras mejoras a consultar.

Las imágenes fueron generadas específicamente para SmartVitra con un estilo fotográfico coherente y sin marcas de terceros.
