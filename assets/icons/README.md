# SmartVitra benefit icons

Iconos locales utilizados por el renderer de PowerPoint.

Cada icono debe:
- tener fondo transparente;
- compartir el mismo estilo visual;
- utilizar preferentemente la identidad visual SmartVitra;
- tener proporciones equivalentes;
- representarse mediante un código semántico estable.

Códigos previstos:

- acoustic
- thermal
- solar_control
- energy
- light
- security
- ventilation
- comfort
- aesthetics
- durability
- maintenance
